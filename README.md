# maplestory-五子棋

朝暮朝夕家族五子棋大赛的赛程表。单页 webapp，无依赖。

**线上地址**：https://syanaooooooo.github.io/maplestory-gomoku/

## 功能

- 8 人单败淘汰赛程表（随机抽签），八强 → 半决赛 → 决赛 + 季军赛
- 点名字选胜者，胜者自动进下一轮；再点一次取消
- 负者比分点一下在 0 / 1 之间切换（三局两胜，胜者固定 2）
- 改了上一轮的结果，下游比赛自动作废重来
- 结果存 localStorage，刷新不丢
- 复制战报到剪贴板 / 导出 `.txt` 战报 / 导出 `.json` 数据
- 亮色暗色自动跟随系统，手机上赛程表变成一轮一轮竖排

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构、规则、奖池 |
| `style.css` | 全部样式（含暗色和手机布局） |
| `app.js` | 赛程数据、晋级逻辑、导出 |

改 `style.css` / `app.js` 后，把 `index.html` 里的 `?v=N` 加一，避免缓存。

## 规则

三局两胜，胜者晋级。第一局开局的人执黑，之后每局由上一局的败方执黑。棋盘一场有一个人提供就行。每局截图发群里才算成绩。
